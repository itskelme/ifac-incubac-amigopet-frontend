# AmigoPet — frontend

> Repositório reservado para o frontend do AmigoPet, ideia apresentada no 6º Desafio de Ideias da INCUBAC/IFAC em 2023. Não contém código.

**Contexto:** IFAC · INCUBAC (incubadora do IFAC) · 6º Desafio de Ideias · 2023

## Sobre

Este repositório foi criado em maio de 2023 para receber o frontend do AmigoPet, projeto inscrito no 6º Desafio de Ideias da INCUBAC. A ideia era um aplicativo voltado à adoção e ao cuidado de animais de estimação. Os detalhes da proposta (funcionalidades, público e modelo do serviço) não foram registrados aqui.

O código do frontend nunca foi publicado neste repositório. Ele fica como registro da participação no desafio.
